## Что исследовано

| Часть | Данные и величины | Основные вопросы |
|---|---|---|
| Спринт 1 · вино | Wine Quality, 6 497 строк: pH, остаточный сахар (г/л), этанол (% об.) | Форма распределений, зависимости, различие среднего pH, выборки и состоятельность оценок |

У данных есть ограничения: wine — конкретный набор образцов, diamonds — историческая учебная таблица. Выводы не распространяются автоматически на все вина или текущий рынок бриллиантов.

В работе есть нормализация, математическое описание распределений, проверка гипотез, обзор восьми алгоритмов генерации и список литературы. Карты выполненных критериев находятся в конце соответствующих частей ноутбука.

## Запуск

### Google Colab

Открыть ноутбук по ссылке в начале README и выбрать **«Среда выполнения → Выполнить все»**. Ячейки используют результаты предыдущих расчётов, поэтому их нужно выполнять сверху вниз.

Подготовительная ячейка восстанавливает вспомогательные модули. Если CSV отсутствуют, они загружаются из первоисточников. Файлы сессии Colab временные; исходники остаются в репозитории и ноутбуке.

### Локально: Jupyter и marimo

Нужны Python 3.12 или новее и установленные зависимости. Из папки проекта:

```sh
python -m pip install -r requirements.txt
```

На macOS вместо `python` может использоваться команда `python3`. Для Jupyter открыть Lab01.ipynb в своей установленной среде и выполнить все ячейки. Для показа интерактивных HTML-результатов собственный ноутбук должен быть отмечен как доверенный.

Приложение marimo запускается отдельно:

```sh
python -m marimo run app_marimo.py
```

Сверху выбирается раздел, внутри него — параметры графиков и экспериментов.

### Что работает без интернета

В Lab01.html встроены данные панелей и Plotly: для графиков и ползунков не нужны Python, сервер или интернет. Для отображения формул используется MathJax с CDN, поэтому без интернета формулы могут остаться в записи LaTeX. Внешние ссылки и кнопка Colab тоже требуют подключения.

В Colab, Jupyter и marimo сама библиотека Plotly загружается с CDN, поэтому для панелей нужен интернет.

## Проверки и воспроизводимость

- В ноутбуке сохранены **27 проверок генераторов**: границы, входные данные, воспроизводимость, дискретные массы и отклонение эмпирической CDF.
- Отдельно выполняются **8 тестовых методов** для генераторов, marimo и сопоставления браузерных расчётов с SciPy.
- Для браузерных тестов нужен **Node.js 20 или новее**. Он устанавливается отдельно с [официального сайта](https://nodejs.org/); `pip` его не устанавливает.

```sh
python --version
node --version
python -m unittest -v test_lab.py test_interactive.py
```

Успешный запуск заканчивается `OK`. Для сохранения нового отчёта о проверке:

```sh
python -m unittest -v test_lab.py test_interactive.py > test_results.txt 2>&1
```

Основные Python-расчёты используют PCG64 и фиксированный seed. Панели выполняют отдельные эксперименты на Mulberry32: последовательности JavaScript и Python при одном seed не обязаны совпадать. Письменные выводы относятся к фиксированным расчётам, а параметры панелей позволяют исследовать их изменение.

В разделе 2.1.8 близость к holdout описана расстояниями KS D и Вассерштейна. Перестановочные p-value по строкам не используются из-за группового разбиения полных повторов. Малое расстояние не является доказательством равенства распределений.

```sh

```
